# Add `PreAuthorizedKey` and take it in `Builder.connectPreAuthorized`

sia_storage 0.13.5 added `PreAuthorizedKey` helpers for random key generation,
seed import/export, and signing indexer creation requests. `PreAuthorizedKey`
is now exported, along with the `PreAuthorizedKeyRequest` and
`SignedPreAuthorizedKeyRequest` records used by `PreAuthorizedKey.signRequest`.

`Builder.connectPreAuthorized` now takes a `PreAuthorizedKey` instead of a
32-byte seed. Wrap the seed with `Sia.preAuthorizedKey` (or
`PreAuthorizedKey(seed: ...)` once the runtime is loaded).

```dart
// before
final sdk = await builder.connectPreAuthorized(
  preAuthorizedKey: savedSeed,
  mnemonic: phrase,
);

// after
final key = await Sia.preAuthorizedKey(savedSeed);
final sdk = await builder.connectPreAuthorized(
  preAuthorizedKey: key,
  mnemonic: phrase,
);
```

Indexer operators can generate a key with `Sia.generatePreAuthorizedKey`, store
its `save()` seed, and sign a creation request for the indexer:

```dart
final key = await Sia.generatePreAuthorizedKey();
final signed = key.signRequest(
  request: PreAuthorizedKeyRequest(
    connectKey: connectKey,
    expiration: DateTime.now().toUtc().add(const Duration(days: 7)),
    totalUses: 1,
  ),
);
```
