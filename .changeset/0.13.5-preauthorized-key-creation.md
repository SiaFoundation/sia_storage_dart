# Add `PreAuthorizedKey`

Adds `PreAuthorizedKey` for generating pre-authorized keys, saving and restoring their 32-byte seed, signing messages, and signing the creation request submitted to an indexer.

```dart
final key = await Sia.preAuthorizedKey();
final seed = key.save();

final request = key.signRequest(
  request: PreAuthorizedKeyRequest(
    connectKey: 'connect-key',
    expiration: DateTime.now().toUtc().add(const Duration(days: 7)),
    totalUses: 1,
  ),
);
```

Restore a saved key with `Sia.preAuthorizedKeyFromSeed(seed)`.
